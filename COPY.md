## Final copy

- **Eyebrow:** /// PandaiBesi Business Factory
- **Headline:** From iron to software, useful things are made the same way: shaped, tested, refined.
- **Subline:** We find, test and run small businesses. AI agents do the groundwork. People make every call.
- **CTA:** Get in touch
- **Ornament caption:** pandai besi (Indonesian), n. blacksmith
- **Approach heading:** How we work
  - **01 / Shaped.** Understand before building. We start from the buyer's problem, how they solve it today and what the evidence says. We outsource thinking, never understanding.
  - **02 / Tested.** Real buyers decide. Every idea meets the market in a small, bounded test. A payment is evidence. A compliment is not.
  - **03 / Refined.** Verify, then improve. A claim that work is done is not proof that it works, so we check the result. Each run teaches the next, and complexity is added only when the work proves it is needed.
- **Idea heading:** Software is one material. Not the only one.
- **Idea body:** People have always turned raw material into useful tools. The method has not changed: shape it, test it, refine it. What we deliver depends on what the buyer needs: a service, software-assisted delivery or a software product. We choose the simplest form that keeps the promise.
- **Contact heading:** Get in touch
- **Contact body:** Questions, ideas or a problem that deserves a better tool.
- **Footer:** © 2026 PandaiBesi. Shaped, tested, refined.
